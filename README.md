## ✨ Features

- 🎨 **Modern Dark Theme** — Clean and elegant dark design
- 📱 **Fully Responsive** — Works perfectly on all devices and screen sizes
- 🌠 **Shooting Stars Animation** — Subtle dynamic background effect on all pages except Contact
- 🎯 **Project Filtering** — Filter projects by category (All, Full Stack, Frontend, UI/UX)
- 💡 **Interactive Skills Section** — Floating icons with grayscale-to-color filter effect
- 📝 **Contact Form** — Real-time validation with success/error messages
- 🔗 **Social Quick Links** — Direct WhatsApp and GitHub links
- ⚡ **Smooth Animations** — Polished hover effects, transitions, and page load animation
- 🔼 **Scroll to Top Button** — Quick navigation back to top
- 📱 **Mobile Side Menu** — Clean hamburger menu for tablet and mobile devices
- 📄 **CV Download** — One-click CV download button
- ♿ **Accessibility** — ARIA labels, keyboard navigation, and focus management

- Any modern web browser (Chrome, Firefox, Edge, Safari)
- [Live Server](https://marketplace.visualstudio.com/items?itemName=ritwickdey.LiveServer) extension (optional, for hot reload)

### Installation

1. **Clone the repository**
   ```bash
   git clone https://github.com/5NOUR/NourEldean-portfolio.git
   Navigate to the project folder
   ```
