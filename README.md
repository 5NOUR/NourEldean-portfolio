# 🚀 Getting Started

## Clone Repository

```bash
git clone https://github.com/5NOUR/NourEldean-portfolio.git
```

## Enter Project Folder

```bash
cd NourEldean-portfolio
```

## Run

Simply open:

```
index.html
```

or use **Live Server** in VS Code.
